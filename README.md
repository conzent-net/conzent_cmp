# Conzent CMP — Google Tag Manager template

The official Google Tag Manager tag template for [Conzent](https://getconzent.com), the consent management platform by Conzent ApS.

One tag loads your Conzent consent banner, blocks tracking until your visitors choose, and signals their choice to Google tags through **Google Consent Mode v2** — with **IAB TCF v2** support (CMP ID 446) when enabled on your site.

## Getting started

1. Create an account at [getconzent.com](https://getconzent.com) and add your site.
2. In Google Tag Manager, add the **Conzent CMP** tag from the Community Template Gallery.
3. Paste your website key from the Conzent dashboard (Step 3 — Install Script) and set the tag to fire on **Consent Initialization — All Pages**.

Full setup guide: [getconzent.com/docs](https://getconzent.com/docs/)

## Platforms

- **GetConzent** (app.getconzent.com) — the default, for all new accounts.
- **Conzent Classic** (conzent.net) — select this only if your account was created on conzent.net.

## Verify your setup

Check your Consent Mode signals with our [Consent Mode Inspector](https://chromewebstore.google.com/detail/ieenpcnlkobelkdkjgfmhbkbleomebop) Chrome extension — Google Consent Mode, Microsoft Clarity, UET, Amazon and IAB TCF signals in one view.
